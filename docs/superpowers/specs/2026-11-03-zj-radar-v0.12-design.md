# zj-radar v0.12.0 bump and cleanup

## Intent

v0.12.0 fixes most of the gaps `docs/zj-radar.md` tracks: #81 (stuck at working, via #84), #82 (`setup --grant`), #86 (the `ledger` option), and the attention keybinds cycling only once (#89, fixed by #91). Bump to it, drop the workarounds, start using what it unblocks, and trim the docs to what is still open.

## Goals

- Bump the wasm, the mise CLI, and the Claude marketplace ref to v0.12.0 in one commit
- Delete `promptSuggestionEnabled` and `awaySummaryEnabled` from `private_dot_claude/settings.json.tmpl` so both return to Claude's defaults (on)
- Add `ledger false` to the `radar` block in `private_dot_config/zellij/config.kdl`
- Bind `Alt e` to `attention-next` and `Alt w` to `attention-prev` in `shared_except "locked"`, using upstream's `MessagePlugin "radar" { name "zj_radar.cmd.v1"; payload "attention-next"; }` form
- Rewrite `docs/zj-radar.md`: add `/plugin update zj-radar-claude@zj-radar` to the bump steps, drop the `--grant` caveat but keep the warning against `setup`/`update`, remove the stuck-at-working section, keep #85 (fixed on main, unreleased) and the right-edge zellij bug as known gaps, document the binds
- Add `Alt-e`/`Alt-w` to the audit table and the direct-binds table in `docs/keybinds.md`

## Non-goals

- Waiting for the #85 light-theme fix, or pinning to an unreleased commit
- `session-next`/`session-prev` binds
- Templating `config.kdl` per machine

## Constraints

- `config.kdl` stays a plain managed file on every machine, so the binds exist even where the wasm is not installed or the radar layout is not loaded
- Never run `zj-radar setup` or `zj-radar update`

## Approaches

- Chosen: plain binds in `config.kdl` for all machines. Layouts cannot hold keybinds, and templating `config.kdl` was ruled out earlier to keep it a plain file
- Rejected: dev_env-only binds through a `config.kdl` template, for the reason above
- Rejected: holding the bump for #85, which would delay every other fix

## Risks to check while building

- `MessagePlugin "radar"` may launch the plugin when no rail is running. Test `Alt e` in a session without the radar layout. If it opens a rail or errors visibly, stop and bring it back before committing
- In zellij, `Alt e`/`Alt w` shadow fish's default Alt-e (edit command line in editor) and Alt-w (describe command). Record this in the `docs/keybinds.md` audit table the same way `Alt-f` is recorded

- Verify the sha256 against the release's `zj_radar.wasm.sha256` asset, fetched with `gh release download`
